Australian Law,
inside Claude.

Ask a question in ordinary English. Retrieve public legislation and supported decisions, with links to their sources.

1. Install once

After extracting this trial pack, open au-law-mcp-1.0.0.mcpb and choose Install in Claude Desktop.

Open the Claude installer

If your browser downloads the file, open the downloaded copy. No terminal commands, separate Node.js installation or legal-data API key are needed. Your usual Claude account and usage limits apply. Internet access is required.

If the file does not open in Claude: Settings → Extensions → Advanced settings → Install Extension…, then select the installation file.

2. Start a new chat

Open a new chat in Claude Desktop. If prompted, review and allow Claude to use Australian Law.

3. Copy this first question

Use Australian Law to retrieve section 18 of the Australian Consumer Law. Show the provision, identify its Act and schedule, and include the official source link.

Look for schedule 2, section 18 of the Competition and Consumer Act 2010. Open the source link and compare it with the returned text.

Two more things to try

Use Australian Law to show section 52 of the Trade Practices Act as at 30 June 2010. Identify the version used and link to the source.
Use Australian Law to find Fair Work Commission decisions about genuine redundancy. Include decision identifiers, source links, and any search limitations.

For your own questions, include the State or Territory and relevant date whenever they matter.

What this preview covers

Start with Commonwealth provisions, historical legislation and supported public decision sources. Coverage is limited: this is not a complete case-law database or an editorial citator. An unavailable source is not proof that no authority exists.

The extension runs locally and sends lookup terms to public sources. Your AI app still handles the conversation and any documents you provide under its own settings. Start your trial with public material.

Something did not work?
  • Restart Claude Desktop, check that Australian Law is enabled under Extensions, then try a new chat.
  • If your firm restricts extensions, ask its administrator to make this one available.
  • Tell the sender your app, operating system, prompt and what happened. Please omit client information.
